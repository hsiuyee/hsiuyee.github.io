Intro

This post provides a step-by-step solution to the online assignment provided by VICI Holdings from a quantitative finance perspective.

In this project, we use the R-squared value instead of the Mean Squared Error for comparison because it provides a more interpretable measure of performance change.

Moreover, in this setting, minimizing the Mean Squared Error is equivalent to maximizing the R-squared value, since $R^2 = 1 - \frac{\sum (y_i - \hat{y}_i)^2}{\sum (y_i - \bar{y})^2},$ where $y_i$ denotes the true value, $\hat{y}_i$ denotes the predicted value, $\bar{y}$ denotes the mean of the true values.

TL;DR: By modifying the basic linear regression model, applying feature scaling, and using ensemble methods, we improved the R-squared score on the validation set by 67%.

R-squared Optimization

In the first stage, we build a basic linear regression model using the scikit-learn library, without any regularization terms, special data transformations, or complex models, to serve as our baseline. We then compare the 12 linear models listed on the sklearn.linear_model page and select the top five as our candidate models.

As we can see, applying the kbins_uniform transformation improves all five of the top models. Moreover, the correlation between train R-squared and validation R-squared is as high as 0.9794. These two findings suggest that kbins_uniform is an effective method for improving R-squared. Intuitively, this transformation converts continuous data into discrete bins, which may reduce the influence of rare extreme events during training.

Feature Scaling-2 (continuous scaling)

While the discretization-based scaling method appears to be powerful, we were interested in whether this result was caused by the limited number of continuous scaling methods considered in our original experiment. Therefore, we reviewed the paper The Impact of Feature Scaling in Machine Learning: Effects on Regression and Classification Tasks and included ten additional scaling methods. Their formulas and results are shown below.

Type Method Formula
1 Min-Max Normalization $X_{\text{norm}} = \frac{X - X_{\min}}{X_{\max} - X_{\min}}$
2 Max Normalization $X_{\text{norm}} = \frac{X}{\max(\lvert X \rvert)}$
3 Z-score Normalization $X_{\text{norm}} = \frac{X - \mu}{\sigma}$
4 Variable Stability Scaling $X_{\text{norm}} = \frac{X - \mu}{\sigma}\cdot\frac{\mu}{\sigma}$
5 Pareto Scaling $X_{\text{norm}} = \frac{X - \mu}{\sqrt{\sigma}}$
6 Mean Centered $X_{\text{norm}} = X - \mu$
7 Robust Scaler $X_{\text{norm}} = \frac{X - X_{\text{median}}}{\mathrm{IQR}}$
8 Quantile Transformation $X_{\text{norm}} = F_{\text{target}}^{-1}!\bigl(F_{\text{emp}}(X)\bigr)$
9 Decimal Scaling Normalization $X_{\text{norm}} = \frac{X}{10^j}$
10 Tanh Transformation $X_{\text{norm}} = \frac{1}{2}\left[\tanh!\left(0.01\frac{X-\mu}{\sigma}\right)+1\right]$
11 Logistic Sigmoid Transformation $X_{\text{norm}} = \frac{1}{1+e^{-q}},q = \frac{X-\mu}{\sigma}$
12 Hyperbolic Tangent Transformation $X_{\text{norm}} = \frac{1-e^{-q}}{1+e^{-q}},q = \frac{X-\mu}{\sigma}$

For detailed definitions of the symbols used in these formulas, please refer to the paper.

Although we evaluated the 12 continuous scaling methods listed above, the best validation R-squared was still significantly lower than that achieved by kbins_uniform. This result suggests that discretization-based scaling methods are more promising than continuous scaling methods for this task. However, due to time constraints, we only adopt kbins_uniform in the following experiments. In future work, other discretization-based scaling methods could also be explored to further improve R-squared.

Ensemble Methods

Finally, we divide the training dataset into four folds to train the same model on different training sets. We then combine these four models using ensemble methods such as StackingLinear, Weighted Average, Simple Average, and Bagging, and compare their performance with that of non-ensemble methods. We find that models using the StackingLinear ensemble method are the most promising, as this method performed best in our validation results. The result is shown below.

Conclusion

In conclusion, we summarize the following interesting findings:

  1. Basic linear regression models are more promising than more complex models.
  2. Discretization-based scaling methods are more promising than continuous scaling methods.
  3. Models using the StackingLinear ensemble method are the most promising.

Overall, these results show that modifying the basic linear regression model, applying feature scaling, and using ensemble methods can lead to a 67% increase in validation R-squared.
